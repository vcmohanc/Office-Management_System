### 4. 要件定義書に無い追加仕様（合意済み・維持）

  当初はレート金額を自動反映して金額欄を readOnly にしていたが、
  xlsx の「上限と申請代金を照らし合わせて」に合わせ、**実費を入力 → 上限超過を警告**に変更した
- **サービススタッフ／派遣先・農家マスタ**
- **分割の備考欄**：希望有無と自由記入のみ（xlsx の「内部処理は現時点では不要」に従う）
- **分割提案の上限金額の自動判定**

### 5. バックエンド実装（MongoDB + Express）
- **モデル**：`Case`（処理・分割・請求控除・退職時・添付・コメント・履歴を内包）、
  `ExpenseType` / `Staff` / `HostFarmer` / `PostageRate` / `Setting`、`Counter`（採番）
- **権限**：`constants/permissions.js` + `middleware/permissions.js` で全エンドポイントを保護。
  `/auth/register` は最初の1人目以外マスタ管理権限必須に修正
- **ルート**：44本（案件CRUD・絞り込み・承認/差戻し/取消・処理状態更新・分割・請求控除・退職時・
  コメント・添付・マスタCRUD・CSV出力・集計）
- **seed.js**：ユーザー4種、マスタ一式、4パターンを網羅したサンプル案件6件
- **注意**：「費用負担先からの回収」フィールドは `recovery`。
  Mongoose では `collection` が予約名のため使えない（`doc.collection` がドライバのCollectionを指す）
